# SIMPLE ECOMMERCE PROJECT — MyShop

A simple e-commerce web application built with **Django** by **Mahendra Kunwar**.

## About

**MyShop** is a personal e-commerce project built from scratch using Django. It includes a storefront, product catalog, and basic shopping functionality, created as a learning and portfolio project.

## Tech Stack

- Python
- Django
- SQLite (default database)
- HTML / CSS / JavaScript (Django templates)

## Features

- Product listing and detail pages
- (add: cart, checkout, user auth, order management, etc.)

## Getting Started

1. Create and activate a virtual environment:

       python -m venv venv
       venv\Scripts\activate        # Windows

2. Install dependencies:

       pip install -r requirements.txt

3. Apply migrations:

       python manage.py migrate

4. Run the development server:

       python manage.py runserver

Then open http://127.0.0.1:8000/ in your browser.
